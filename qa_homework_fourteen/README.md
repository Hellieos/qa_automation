# 📘 API Testing Project – Homework

Цей проєкт є реалізацією фреймворку для API-тестування в межах Домашнього завдання №14, створеного на основі **Official Joke API**, який використовувався у Домашньому завданні №12.

Мета цього проєкту — продемонструвати:

- Використання **Vitest** як фреймворку для тестування  
- Створення багаторазового HTTP-сервісу для запитів за допомогою **fetch**  
- Описання API-ендпоінтів у спеціальному **API Object (JokesApi)**  
- Роботу з **DTO-моделями TypeScript**  
- Написання автоматизованих API-тестів  
- Запуск усіх тестів однією простою командою  

All requests target the public API:  
https://official-joke-api.appspot.com/

---

## Running Tests

To run the entire Vitest suite:

- npm run test


To run tests in watch mode (auto-re-run on file changes):

- npm run test:watch
