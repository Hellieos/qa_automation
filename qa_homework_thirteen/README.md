# 🐾 QA Homework 13 — Інтеграційні та контрактні тести (TheCatAPI + Pact)

## Опис проєкту
Цей проєкт створений за допомогою:
- **Mocha + Chai** — для інтеграційних тестів;
- **Axios** — для виконання HTTP-запитів;
- **Pact** — для контрактного (consumer–provider) тестування;

---

## Що тестується
1. **Інтеграційні тести** для [TheCatAPI](https://thecatapi.com/):  
   Перевіряється взаємодія між модулями  
   `images → votes → favourites` із реальною API.
2. **Контрактні тести (Pact)**:  
   - для **Dog API** — створення та верифікація контракту споживача;  
   - для **Petstore API** — додатковий приклад контрактного тесту (опційно).

---

## | Команда             | Опис                                                            |
| ------------------- | --------------------------------------------------------------- |
| `npm run test`      | Запуск **інтеграційних тестів** (TheCatAPI, CommonJS).          |
| `npm run test:pact` | Запуск **контрактних тестів** (Dog API, Petstore).              |
| `npm run test:all`  | Послідовний запуск обох типів тестів.                           |
